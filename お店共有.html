ふたりで共有する

このページは静的HTMLのため、データはそれぞれの端末のブラウザに保存されます。相手とは「共有リンク」か「JSONファイル」で受け渡しします。受け取った側は統合を選ぶと、両方のリストが合わさります（同じお店は新しく編集された方を採用）。

いまはローカルファイル（file://）として開いているため、共有リンクは相手の端末では開けません。GitHub Pages や Netlify などに置いて https で公開すると共有リンクが使えます。それまではJSONファイルで受け渡ししてください。

Google マップ連携（APIキー）

APIキーを設定すると、マップタブが Google マップで表示され、位置検索にも Google のジオコーディングを使います。未設定のときは OpenStreetMap で表示します。

キーの取得手順（Google Cloud Console）:
  1. プロジェクトを作成し、Maps JavaScript API と Geocoding API を有効化
  2. 「認証情報」でAPIキーを作成
  3. キーの制限で「ウェブサイト」を選び、このページのURL（例: https://example.github.io/*）だけを許可
キーはこの端末にのみ保存され、共有リンクやJSONには含まれません。
